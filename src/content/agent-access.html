  • 先明确日期口径：这批按消费时间，还是入账时间记账？未明确时只识别和核对。

01 · MCP 连接

端点：/mcp（本站协议、主机和端口 + /mcp）
传输：Streamable HTTP

每次请求携带 Ledger 网页账号密码，不用先登录网页，不用 token、验证码或 OAuth。

Authorization: Basic <base64(UTF-8 用户名:密码)>
Content-Type: application/json
Accept: application/json, text/event-stream

这里使用记账账号，不是服务器 SSH 账号。公开页面不包含任何真实账号密码或模型密钥。

Base64 不是加密。传输实际密码时使用 HTTPS 或 SSH 隧道；当前若通过 HTTP 访问，请先配置加密连接。

02 · 能做什么

  • list_transactions · 筛选、分页查询流水
  • get_transaction · 查询一笔流水
  • create_transaction · 新增记账
  • update_transaction · 修改已有流水
  • delete_transaction · 删除指定流水
  • list_categories / list_projects · 查询分类与项目

普通账号通过 MCP 只能读写自己的流水；管理员可以读写全部。改密后旧凭据立即失效。

03 · 配置与首次调用

Codex 本地配置示例：将 URL 换成本站的 HTTPS 地址或 SSH 隧道地址。环境变量 LEDGER_MCP_AUTH 的值应为完整的 Basic … 请求头，并对运行 Codex 的进程可见。

[mcp_servers.ledger]
url = "https://YOUR_LEDGER_ORIGIN/mcp"
env_http_headers = { Authorization = "LEDGER_MCP_AUTH" }

用 MCP 客户端初始化后读取 tools/list，即可获取准确的参数定义。手动 HTTP 验证可以先发送：

{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ledger-agent","version":"1.0"}}}

随后发送 notifications/initialized 和 tools/list，每次都带上同一 Basic 请求头。GET /mcp 不是说明页面；无凭据或错误凭据返回 401。浏览器 Origin 请求会返回 403，超过限额返回 429。
